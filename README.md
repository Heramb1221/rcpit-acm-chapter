## About The Project

The RCPIT ACM Chapter Website is the official digital platform for the Association for Computing Machinery Student Chapter at R. C. Patel Institute of Technology, Shirpur. Founded in 2025, the chapter needed a production-quality public-facing web presence to communicate its mission, showcase events, present leadership, and serve as a community hub for 400+ students.

This project was designed and engineered from the ground up as a statically exported Next.js application — a deliberate architectural choice that prioritizes performance, zero-cost deployment, and long-term maintainability. The site handles all primary chapter functions: organizational storytelling, event discovery with rich detail modals, team directory with interactive profile cards, a contact interface with embedded maps, and membership outreach.

## Tech Stack

| Layer | Technology | Rationale |
|---|---|---|
| Framework | Next.js 15.5 (App Router) | File-based routing, static export support, React Server Components capability |
| UI Library | React 19 | Latest stable React with concurrent features |
| Styling | Tailwind CSS v4 | Utility-first CSS with zero runtime overhead; v4's new `@import "tailwindcss"` syntax |
| Icons | react-icons 5.5 | Lightweight icon pack (FaGithub, FaLinkedin used in team page) |
| Font | Geist (next/font) | Vercel's design system font, auto-optimized |
| Linting | ESLint 9 + eslint-config-next | Enforces React and Next.js best practices |
| Build | Turbopack | Faster local rebuild cycles vs. webpack |
| Deployment | Static Export | Output: HTML/CSS/JS bundle deployable to any CDN or static host |
